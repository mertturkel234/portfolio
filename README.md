## Elevator Pitch

A curated, single-page portfolio presenting selected software projects, leadership experience, and technical expertise. Designed with a modern dark aesthetic, scroll-reveal animations, and responsive layout — optimized for recruiters and engineering managers reviewing candidate profiles.

---

## Sections

| Section | Content |
|---------|---------|
| **Hero** | Introduction, CTA links (GitHub, LinkedIn, CV download) |
| **About** | Background, focus areas, career goals |
| **Work** | Featured projects with tech stack and links |
| **Leadership** | IEEE CyberSec, community involvement |
| **Contact** | Email and social links |

## Tech Stack

- Semantic HTML5
- Custom CSS (CSS variables, grid, flexbox, animations)
- Vanilla JavaScript (scroll reveal, smooth navigation)
- Phosphor Icons
- Google Fonts (Inter, Space Grotesk)

## Installation & Usage

```bash
git clone https://github.com/mertturkel234/portfolio.git
cd portfolio

# Option 1: Open directly
open index.html        # macOS
start index.html       # Windows

# Option 2: Local server (recommended)
npx serve .
# Visit http://localhost:3000
```

### GitHub Pages Deployment

1. Push to `main` branch
2. Settings → Pages → Source: `main` / root
3. Site live at `https://mertturkel234.github.io/portfolio/`

## Security Considerations

- No backend or user data collection — static site only
- External links use `target="_blank"` with `rel="noopener"`
- CV PDF hosted in `/assets` — no sensitive data in source code
